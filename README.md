# 🥗 식약처 영양성분 DB 기반 AI 푸드 영양 스캐너

> 음식 사진을 찍으면 AI가 부피/식기 비율을 분석하여 **예상 그램수(g)**를 추정하고, **식품의약품안전처(식약처) 식품영양성분 DB**와 연동하여 정확한 칼로리와 탄·단·지·나트륨을 계산해 주는 반응형 웹/모바일 어플리케이션입니다.

---

## ✨ 주요 기능

1. **사진 한 장으로 다중 음식 자동 분리 & 중량(g) 추정**
   - 한상차림(밥, 국, 반찬들) 또는 단일 메뉴 사진을 찍으면 각 음식을 개별 검출
   - 식기/밥공기/숟가락 대비 시각적 부피 분석을 통해 섭취 예상 그램수(g) 및 1회 제공량 대비 인분 비율 추정
   - AI가 왜 해당 무게로 추정했는지 시각적 근거(Visual Cues) 설명 제공

2. **인터랙티브 그램수(g) 미세조정 슬라이더**
   - AI 추정치를 바탕으로 사용자가 슬라이더나 숫자 입력, 빠른 인분 버튼(0.5인분, 1인분, 1.5인분)으로 1초 만에 조정 가능
   - 그램수를 조절하는 즉시 칼로리, 탄수화물, 단백질, 지방, 당류, 나트륨이 실시간으로 비례 재계산

3. **식약처 영양성분 DB (SQLite FTS5 고속 검색) 완벽 연동**
   - 식품안전나라의 **음식 DB**, **가공식품 DB** 등 수만 건의 데이터를 초고속으로 검색 및 매핑
   - AI가 인식한 음식을 원하는 식약처 표준 메뉴로 즉시 변경 가능

4. **식약처 엑셀(`.xlsx`) 파일 웹에서 즉시 드래그앤드롭 등록**
   - 식품안전나라에서 내려받은 `.xlsx` 파일을 웹 화면에서 업로드하면 엑셀 헤더를 자동 분석하여 DB에 즉시 적재

5. **Google Gemini 2.5 Flash / 1.5 Flash Vision AI 탑재**
   - 최신 멀티모달 비전 모델 적용
   - API 키가 없어도 모든 UI와 슬라이더 기능을 즉시 테스트해볼 수 있는 **체험(Mock) 모드** 내장

## 🚀 빠른 시작 (실행 방법)

### 1. 간편 실행 (Windows)
프로젝트 폴더 내 `run.bat` 파일을 더블클릭하거나 터미널에서 다음 명령어를 실행합니다:

```bash
cd C:\Users\hanna\.gemini\antigravity\scratch\food-nutrition-app
.\venv\Scripts\python.exe run.py
```

실행 즉시 로컬 서버(`http://127.0.0.1:8000`)가 기동되며 브라우저가 자동으로 열립니다.

## 🔑 Google Gemini API 키 설정

1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속 (구글 로그인)
2. **[Create API key]** 버튼 클릭 후 생성된 키 복사 (무료)
3. 웹 화면 우측 상단의 **[API 키]** 버튼을 눌러 입력하거나, 프로젝트 루트의 `.env` 파일에 저장:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```

## 📊 식약처 엑셀(`.xlsx`) 파일 등록 방법

1. [식품안전나라 영양성분 DB 내려받기](https://various.foodsafetykorea.go.kr/nutrient/general/down/historyList.do) 페이지에서 **[음식 DB]** 또는 **[가공식품 DB]** 엑셀 파일 다운로드
2. 웹 화면 우측 상단의 **[식약처 엑셀]** 버튼 클릭
3. 다운로드한 `.xlsx` 파일을 드래그앤드롭하여 업로드하면 수만 건의 식품 데이터가 SQLite DB에 자동 적재됩니다.
